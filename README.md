# Archivarius

- Python, HTML, Javascript, CSS;
- Flask, sqlite3;
- pywebview, pyinstaller;

## Como instalar

1. Baixe o projeto do GitHub (.zip)
2. Vá em algum diretório do seu computador e descompacte em um novo diretório (ex: ./Documentos/Archivarius)
3. Dentro do direório criado (ex: "Archivarius"), abra uma janela do terminal/console.
4. Para criar o executável, digite o seguinte comando:

`pyinstaller app.spec`

--> Serve para Linux, Windows, Mac

5. Vá para o novo diretório criado automaticamente (ex: "dist").
6. Dê clique duplo para executar. Se preferir no terminal, só rodar o seguinte:

`./archivarius`

7. Aproveite!
